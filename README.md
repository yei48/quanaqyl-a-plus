# QuanAQYL A+ — Physics Learning Portal

Учебный портал по физике на русском, казахском и английском. Эта версия подготовлена для **Vercel + Supabase**.

**Начни с [пошаговой инструкции для Vercel](docs/VERCEL_SETUP_RU.md).** Перед рабочим запуском нужны проект Supabase, две SQL-миграции и три переменные окружения. Сам импорт GitHub-репозитория не создаёт базу данных.

## Что входит

- Диагностика, 36 учебных задач, подсказки и разбор решений.
- Учебный маршрут по результатам, прогресс, календарь, серия занятий и награды.
- Physics Hub: теория для 9–12 классов, 36 глав, 40 материалов; состояния «скоро» для 7–8 классов.
- Существующая интерактивная симуляция равноускоренного движения.
- Магазин Kyōmei: 60 виртуальных товаров, покупки за учебные баллы и коллекция.
- Редактируемый профиль и личная фотография.
- Перемещаемый Pomodoro: работа/отдых, пауза, сохранение состояния и статистика.
- Регистрация и вход по e-mail и паролю, подтверждение почты, восстановление пароля.

## Технологии и данные

| Часть | Реализация |
| --- | --- |
| Приложение | Next.js 16, React 19, TypeScript; стандартный Node.js runtime на Vercel |
| Авторизация | Supabase Auth; сервер проверяет пользователя через `getUser()` |
| Учебные данные | PostgreSQL Supabase, отдельная закрытая схема `quanaqyl` |
| Фотографии | Приватный Supabase Storage bucket `profile-photos`, RLS по ID владельца |
| SQL | `pg`, параметры `$1…`, транзакции на одном соединении |
| Конкурентные операции | Транзакционные блокировки покупок и пауз; версии состояния Pomodoro |

Пароли хранит Supabase Auth. В клиентском коде есть только публичный URL и publishable key. `DATABASE_URL` доступен только серверу. Сервисный ключ Supabase для этой реализации не нужен.

Схема `quanaqyl` закрыта для `anon` и `authenticated`; браузер обращается к собственным API приложения. В каждом API используется проверенный сервером ID пользователя. Фото дополнительно защищены политиками Storage. Схему `quanaqyl` нельзя добавлять в Exposed schemas Data API.

## Разработка

Нужны Node.js 22 и pnpm 11.25.0.

```bash
npm exec --yes --package=pnpm@11.25.0 -- pnpm install --frozen-lockfile
```

Скопируй `.env.example` в `.env.local` и заполни значения из собственного Supabase-проекта. Не добавляй `.env.local` в Git. Миграции можно выполнить в Supabase SQL Editor либо командой:

```bash
pnpm db:migrate
pnpm dev
```

Открыть `http://localhost:3000`.

```bash
pnpm test
pnpm typecheck
pnpm build
pnpm start
```

`pnpm test` использует временный PostgreSQL-движок PGlite; не обращается к рабочему Supabase. Проверяет учебную логику, теорию/переводы, SQL-миграции, изоляцию данных и фото, транзакционный откат, покупки, повторы запросов, Pomodoro, лимиты пауз и формы входа. Работу реальной почты и подключения Vercel → Supabase нужно проверить после настройки сервисов.

## Структура

- `app/api/` — авторизованные серверные операции.
- `app/auth/`, `lib/supabase/`, `proxy.ts` — вход, обновление сессии, подтверждение и восстановление.
- `db/` — PostgreSQL-подключение и параметризованные запросы.
- `supabase/migrations/` — таблицы, ограничения, приватное хранилище фото и политики доступа.
- `components/` — интерфейс, таймер, профиль, теория, магазин и графики.
- `lib/catalog.ts`, `lib/physics-theory.ts`, `lib/i18n.ts` — задачи, теория, переводы.
- `scripts/` — миграции и проверки.
- `docs/VERCEL_SETUP_RU.md` — настройка сервисов и проверка после публикации.

## Перенос с Sites

Зависимости от Cloudflare Workers, D1, R2, Vinext и входа через заголовки Sites удалены из этой версии. Оригинальный сайт Sites продолжает работать отдельно; версия до переноса сохранена в истории Git.

**Существующие аккаунты, фотографии и результаты из Sites не перенесены.** У Supabase свои ID пользователей; эта установка начинает с новой базы. Для сохранения прежней истории потребуется отдельный экспорт и проверенное сопоставление аккаунтов. Автоматическое объединение по имени или e-mail не выполняется.

## Ограничения учебной версии

Персональный маршрут использует понятные правила по результатам, а не подключённую языковую модель. LLM-ментор, SMS-регистрация и Google OAuth не подключены. Диагностика учебная: ответы присутствуют в клиентском каталоге, поэтому это не защищённая экзаменационная система. История API ограничена 500 последними попытками. Pomodoro измеряет прошедшее время, а не фактическое внимание ученика. Магазин использует виртуальные баллы, без денежных платежей.
